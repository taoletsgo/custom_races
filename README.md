A racing core for loading and creating GTA Online races in FiveM

## 📺YouTube Overview
[![IMAGE ALT TEXT HERE](https://i.ytimg.com/vi/wBwX8a3b1YY/maxresdefault.jpg)](https://www.youtube.com/watch?v=wBwX8a3b1YY)

## 🤖Features
- ☑ Race mode
- ☑ Creator mode with [multiplayer support](https://www.youtube.com/watch?v=rYjyW5i3Z4c)
- ☑ Include a All-In-One GTA style trainer
- ☑ Full support for Xbox controller
- ☑ 13 languages

## 🛠️Installation
- Download [oxmysql](https://github.com/overextended/oxmysql/releases)
- Download [custom_races](https://github.com/taoletsgo/custom_races/releases)
- Modify the `server.cfg` file
```
ensure oxmysql
ensure custom_races
```
